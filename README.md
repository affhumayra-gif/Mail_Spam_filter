# 📱 SMS Spam Classification

A machine learning project that classifies SMS messages as **spam** or **ham** (legitimate). It starts with a TF-IDF + Linear SVM baseline, then compares several classical models, engineers SMS-specific features, and tunes the decision threshold for a precision-first spam filter.

**Notebook:** `SMS_Spam_Classification_Final-2.ipynb`
**Dataset:** [SMS Spam Collection (Kaggle / UCI)](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset)

## Overview

The notebook is split into two parts:

1. **Part 1**: a complete, tuned baseline pipeline (text cleaning → TF-IDF → LinearSVC).
2. **Part 2**: answers the question *"Is that actually the best choice, and how far can it be pushed?"* by trying richer features, six more model families, and threshold tuning.

Because the data is imbalanced (~87% ham), accuracy alone is misleading. Part 2 therefore optimises and reports **spam-class precision, recall and F1**, along with PR-AUC.

## Part 1: SVM Baseline

1. **EDA**: class distribution, message length / word-count histograms, and word clouds for spam vs. ham.
2. **Preprocessing** (`clean_text`): lowercasing, removing URLs, emails, digits and punctuation, stopword removal, and WordNet lemmatisation. Duplicates are dropped.
3. **Split**: 80/20 stratified train/test split (`random_state=42`).
4. **Model**: `TfidfVectorizer(max_features=5000, ngram_range=(1,2))` → `LinearSVC` in a scikit-learn `Pipeline`.
5. **Tuning**: `GridSearchCV` over `C ∈ {0.1, 1, 10}` with 5-fold CV (best: `C=1`).
6. **Validation**: 5-fold cross-validation on the full dataset.
7. **Inference**: a `predict_sms(text)` helper that returns `"Spam"` or `"Ham"`.

## Part 2: Model Comparison and Going Further

**Better features.** Part 1's cleaning strips digits, punctuation and URLs, which are exactly the signals that give spam away (`£1000`, `CALL 0906...`, `!!!`, `www.`). Part 2 keeps the raw text and combines three views:

- Word TF-IDF (1–2 grams) that keeps `£ $ € !` as tokens
- Character n-gram TF-IDF (2–5, word-bounded), which is robust to misspellings and txt-speak
- Hand-crafted features: length, digit count/ratio, uppercase ratio, `!` / `?` counts, has-URL, has-phone-number, has-currency, average word length, number of ALL-CAPS words

**Models compared** (same split, same features, 5-fold stratified CV optimising spam-class F1, test set touched once per model):

- LinearSVC
- Logistic Regression
- Complement Naive Bayes
- Multinomial Naive Bayes
- Random Forest
- XGBoost
- LightGBM

**Threshold tuning.** For a spam filter, blocking a real message is usually worse than letting a spam through. Using out-of-fold predictions on the training set only, the notebook picks the lowest decision threshold that keeps precision ≥ 99%, then measures the real cost on the test set.

**Analysis.** The notebook also includes a leaderboard, precision-recall curves, confusion matrices, error analysis of false positives and false negatives, and the top spam-/ham-indicative features from Logistic Regression coefficients.

## Results

**Part 1 baseline (LinearSVC, cleaned text)**

| Metric | Score |
|---|---|
| Accuracy | 0.9845 |
| Precision (spam) | 0.9832 |
| Recall (spam) | 0.8931 |
| F1 (spam) | 0.9360 |
| 5-fold CV accuracy | 0.9795 |

**Part 2 classical models (5-fold CV F1 on the training set)**

| Model | CV F1 |
|---|---|
| Multinomial NB | **0.9593** |
| LinearSVC | 0.9586 |
| Logistic Regression | 0.9562 |
| Complement NB | 0.9523 |
| LightGBM | 0.9412 |
| XGBoost | 0.9398 |
| Random Forest | 0.9332 |

**Best model on the held-out test set (Multinomial NB)**

| Setup | Precision | Recall | F1 |
|---|---|---|---|
| Default threshold | 0.9766 | 0.9542 | 0.9653 |
| Tuned threshold (precision ≥ 99%) | 0.9917 | 0.9160 | 0.9524 |

With the tuned threshold, the model produced only **1 false positive** (a harmless "Nokia phone is lovly.." message) and **11 false negatives** on the 1,034 test messages. The richer features lifted spam F1 from 0.936 (Part 1) to about 0.965, mainly through better recall.

> Exact numbers may vary slightly with library versions.

## Getting Started

### Prerequisites

- Python 3.9+
- Jupyter Notebook / JupyterLab, or [Google Colab](https://colab.research.google.com/)

### Installation

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

pip install pandas numpy matplotlib seaborn wordcloud nltk scikit-learn xgboost lightgbm joblib
```

NLTK data (`stopwords`, `wordnet`) is downloaded automatically by the notebook.

### Data

1. Download `spam.csv` from the [Kaggle dataset page](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset).
2. Place it next to the notebook. On Colab, the notebook will prompt you to upload it.

## Usage

Open the notebook and run the cells in order:

```bash
jupyter notebook SMS_Spam_Classification_Final-2.ipynb
```

Quick prediction using the Part 1 model:

```python
predict_sms("Congratulations! You have won a free iPhone. Click here now.")  # -> Spam
predict_sms("Hi, are we meeting tomorrow at 3 PM?")                          # -> Ham
```
